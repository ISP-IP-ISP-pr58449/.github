<p>流程本身不复杂，复杂的是每个节点该确认什么。本文按时间线把采购分成六个节点，逐段说明要做的事和容易漏的地方，中间给一张节点清单表，最后讲付款、售后与续费，附常见问答。</p>
<h2>一、节点一：把需求写成一页纸</h2>
<p>写四行：用途、地区、并发设备数、需要几个地址。四行写完再去找服务方，沟通效率完全不同。很多人一上来问价格，对方只能给一个泛泛区间。</p>
<p>用途要具体到环节。“店铺后台日常操作”和“数据采集”对带宽与地址数量的要求差很远，写清楚才不会买错档。</p>
<h2>二、节点二：三家同时询价</h2>
<p>同时问三家，把回复整理成同一张表对比。重点看四项：地址是否独享、带宽是否保底、换地址规则、故障响应时长。</p>
<p>报价低于市场均价一半的，先问地址来源。价格异常通常对应共享密度高或者转售层级多，便宜的部分会在后面用时间换回来。</p>

<h2>三、节点三：验货只查三项</h2>
<p>验货要一段临时地址，查归属国家与城市、ASN、使用类型。三项对上再谈付款，不肯给测试的态度本身就是信息。</p>
<p>顺手测一次延迟，从你常用网络到出口。这个数字后面选机型、定带宽都要用，比自己猜准。</p>
<h3>测试地址能测出什么</h3>
<p>能测出归属、ASN、延迟和丢包，测不出共享人数和长期稳定性。后两项只能靠合同条款和小批量试用。</p>
<h2>四、节点四：下单与付款</h2>
<p>订单写清六项：地址数量、带宽、计费周期、变更规则、交付时限、故障响应。聊天记录不算合同，尽量要一份可保存的确认单。</p>
<p>付款方式上，对公转账能开票但流程慢，在线支付快但留痕弱。金额大的建议走可追溯的方式，后面有争议好处理。</p>

<h3>首月优惠要看续费价</h3>
<p>很多方案首月半价，第二个月恢复原价。把续费价写进对比表，按十二个月总成本算，才看得出真实差距。</p>
<h2>五、节点五：开通与切换</h2>
<p>开通后会拿到账号密码、白名单授权或隧道配置，三者对应不同设置方式。拿到后先在测试机连通，再上生产设备。</p>
<p>上生产前做一次全流程验证：地址、DNS、延迟、并发。四项过了再切业务，别在业务高峰做切换，出了问题没人兜。</p>
<p>切换当天把旧会话清干净，缓存和登录态一起清，否则会出现新地址配旧会话的情况，看起来像没生效，实际是残留状态。</p>
<h2>六、节点六：验收与售后</h2>
<p>验收看三件事：连续三天地址稳定、延迟在预期范围、工单有回复。三项都过，进入正常使用阶段。</p>
<h3>售后要留人</h3>
<p>售后要留一个直接联系人。走代理渠道的，排障往往要转一手，提前问清响应时限，遇到问题才不会干等。</p>
<h3>续费提醒设两次</h3>
<p>到期前一周和前一天各设一次提醒。自动停机的方案断了再开，配置可能要重做，中断损失远大于续费金额。</p>
<h2>常见问答</h2>
<h3>整个流程要多久？</h3>
<p>答：需求清楚的情况下，直营渠道当天到三天能开通，转售渠道常见一周。急单要提前说明，并把交付时限写进订单。</p>
<h3>一定要先付款才能测试吗？</h3>
<p>答：多数服务方给短期测试地址，不需要预付。要求全额预付才给测的，谨慎对待，这种条件往往说明对方是转手卖。</p>
<h3>能开发票吗？</h3>
<p>答：企业采购多数可以，需要提供开票信息。个人买家通常只能拿到收据，下单前问清，别等月底报销才发现开不了。</p>
<h3>买了不合适能退吗？</h3>
<p>答：看条款。多数按剩余天数折算，部分不支持退款。开通前确认退订规则，比事后争论有用。</p>
